# Yakit 模块专精：Fuzzer、MITM 与 Codec

前面的专题里你已经**顺手用过**这三个模块：Web Fuzzer 手搓过注入请求、MITM 劫持过商城下单、Codec 对照过 HTML 转义。但"顺手用"和"用透"之间还差一层——本专题把三个模块各自放到聚光灯下，各配一道**只有对应模块的动作形态才能完成**的题：

- **Web Fuzzer 重放与自定义头**：浏览器的表单永远发不出 `X-Replay` 这样的自定义请求头。要在重放请求里自由增删改头部，只有手搓/重放工具做得到；
- **MITM 会话链**：登录拿会话、复用会话访问——两步必须在**同一条被观察的流量链**里完成。固定预置 Cookie 在这里是诱饵：真链验证的是动态签发的会话，逼你先代理观察真实流量，再中途复用；
- **Codec 解码链**：双重 URL 编码的 SSRF payload，编码错一环靶机就打不通。解码能力就是攻击能力。

建议按顺序完成：三题分别复用你已熟悉的靶场路径（命令模拟接口、商城登录、SSRF 接口），不再有新攻击面——**考的全是工具动作本身**。
