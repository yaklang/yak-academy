# Yakit 模块专精：一条业务链打穿商城

前面的专题里你已经**顺手用过**不少模块：Web Fuzzer 手搓过注入请求、MITM 观察过商城流量、Codec 对照过 HTML 转义。但"顺手用"和"组合拳"之间还差一层——真实渗透里，一次完整的攻击往往要**多个模块接力**：先挂代理看清业务怎么跑，再写脚本让工具自动改包，然后手搓请求完成最后一击，最后用编码知识穿过校验边界。

本专题只有**一道综合题**：靶场商城的一件商品，你要用 1 分钱把它买下来，并读出本实例的 flag。整条链四步，每一步对应一个 Yakit 模块，缺一不可：

1. **MITM 代理观察**——挂上代理，用真实账号在商城走一遍登录与下单流程，看清业务请求长什么样（整条链的起点：先观察，再动手）；
2. **热加载自动改包**——在 MITM 里挂一段 Yak 脚本，让经过代理的订单请求**自动**把 `total_price` 改写为 `0.01`（热加载是 Yakit 代理链相对纯手搓工具的杀手锏：改写逻辑即写即生效，不用重启代理）；
3. **Web Fuzzer 手搓重放**——把订单请求发到 Fuzzer，手工加上自定义头 `X-Mall-Internal: yakit-order`（订单系统的"内部下单通道"校验，浏览器表单永远发不出这种头），重放完成 1 分钱下单；
4. **Codec 编码链**——靶机为订单系统开了个内部校验端点，口令要先 base64 再 URL 编码才能送达（`+` 和 `=` 不转义会在半路被破坏）。

配套教程会逐步讲解每个模块怎么用，题目则把四步连成一条完整的业务链攻击。
