# 服务端攻击面：SSRF 与文件上传

当攻击发生在**服务器内部**时，浏览器能看到的往往只是冰山一角。本专题聚焦两类服务端漏洞：

- **SSRF（服务端请求伪造）**：让服务器替你访问它自己才能到达的内网接口。明文参数与 JSON 参数两种形态都练一遍，并了解 Yakit 反连平台（OOB）如何验证"无回显"的盲 SSRF；
- **文件上传**：魔数（文件头）校验看似比扩展名靠谱，但"GIF 头 + 脚本身体"的多态文件照样骗过它。学会在 Web Fuzzer 里手工构造 multipart 上传请求。

本专题的题相对综合，建议先完成《Yakit 上手与流量操控》专题再进入。
