# Yakit 上手与流量操控

本专题是 Yakit 实战的第一站，围绕三个核心交互面展开：

- **Web Fuzzer**：手工构造、修改、重放 HTTP 请求——安全测试中使用频率最高的模块；
- **MITM 交互式劫持**：以代理身份观察真实业务流量，随手拦截、篡改、放行；
- **Codec 编解码**：看懂 base64 / URL / HTML 实体等编码，攻击 payload 的"翻译官"。

三个教程各配一道内置靶题（一个教程对应一道题），完成本专题即打通"发包—抓包—编码"的第一轮闭环。后续专题（SQL 注入、会话越权、服务端攻击面）都建立在这些基本功之上。

建议按顺序学习：先用 Web Fuzzer 发出第一个请求，再体验 MITM 改包，最后用 Codec 观察编码细节。
