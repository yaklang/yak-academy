# SQL 注入实战：从万能密码到拖库

SQL 注入是 Web 安全的经典战场，本专题用三道题走完注入的完整技能线：

1. **登录绕过（万能密码）**：理解字符串拼接 SQL 的致命缺陷，体会参数化查询为什么能免疫；
2. **UNION 拖库**：探测列数、对齐类型、把任意查询"焊"进结果集；
3. **闭合技巧**：真实业务的注入点往往裹着引号、括号和附加条件，学会拆"包装纸"。

配套工具以 Web Fuzzer 为主（构造与重放注入请求），Codec 负责 URL 编码，最后再用漏洞检测与数据库客户端做自动化对照。每道题都来自同一个 vulinbox 靶场实例，注入技巧可以在题与题之间复用。
