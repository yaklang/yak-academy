# 会话、令牌与越权

很多"黑客电影式"的攻击并不发生在数据层，而是发生在**身份层**：拿到一个会话凭证、伪造一个令牌，就能以别人的身份行事。本专题覆盖两种典型凭证的攻防：

- **服务端会话（Cookie）**：会话标识一旦泄露或可预测，即可冒充他人——配合 SQL 注入把会话表拖出来，再重放 Cookie 验证；
- **JWT 令牌**：`alg=none` 是 JWT 最经典的实现缺陷。用 Codec 把 token 拆开、重组，理解"服务端到底信了 token 里的什么"。

学完本专题，你会在 History 流量审计里对照"正常请求 vs 冒充请求"的差异，并了解如何用插件市场的现成 POC 批量检测这类缺陷。
